# Resource managers
- this is used to manage resource like limit and request
- most common resources to specify are CPU and memory (RAM); there are others.
```
 resources:
      requests:
        memory: "64Mi"
        cpu: "250m"
      limits:
        memory: "128Mi"
        cpu: "500m"

```

Requests → The minimum guaranteed amount of CPU/Memory your container will get.
Limits → The maximum allowed CPU/Memory your container can use.


Check usage of your running pods:
```
kubectl top pod
```

Q: if k8s is only limit no request in resources then ?
A: If you specify only resource limits and no requests, Kubernetes automatically sets the resource requests equal to the specified limits (requests = limits).
