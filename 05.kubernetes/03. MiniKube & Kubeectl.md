## Deployment

``` 
    kubectl create deployment NAME --image= image 

    kubectl create deployment ngnix-depl --image=ngnix

    kubectl apply -f <file_name>.yaml

```

#### format 

```
    apiVersion: apps/v1
    kind: Deployment
    metadata:        # who am I / how do I get found
    spec:
    replicas:      # how many
    selector:      # how the Deployment finds its own Pods
    template:      # the actual Pod spec (this is a Pod definition nested inside)
        metadata:
        spec:
            containers:
```
