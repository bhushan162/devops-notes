### 1. `template.metadata.labels`

```yaml
template:
  metadata:
    labels:
      app: myapp
```

- Every time this Deployment spins up a new Pod, it stamps this key-value label (`app: myapp`) onto that Pod's metadata.
- Think of an assembly line stamping a brand logo on every phone coming off the belt — every Pod born from this template wears the `app: myapp` name tag.

### 2. `spec.selector.matchLabels`

```yaml
spec:
  selector:
    matchLabels:
      app: myapp
```

- This is the query rule the Deployment Controller uses. It constantly scans the namespace asking: "How many Pods right now are wearing the label `app: myapp`?"

```
┌────────────────────────────────────────────────────────┐
│                 DEPLOYMENT CONTROLLER                   │
│                                                          │

                             │
            ┌────────────────┴────────────────┐
            │ Does it see enough matching      │
            │ Pods right now?                  │
            └────────┬───────────────┬─────────┘
                      │               │
                  ( YES )           ( NO )
                      │               │
                      ▼               ▼
              [ Keep Running ]   [ Create new Pod using  ]
                                 [ 'template' blueprint   ]
                                             │
                                             ▼
                                 ┌────────────────────────┐
                                 │        NEW POD         │
                                 │                         │
                                 │  Metadata Label:        │
                                 │    app: myapp  ◄────────┼── Stamped by template!
                                 └────────────────────────┘
```
