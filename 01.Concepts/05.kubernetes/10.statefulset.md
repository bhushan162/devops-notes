# statefulset
- statefulset is used for stateful application , application that store there previous state 
- all stateful replicas they dont use the same physical storage althi they sharae same data 

#### The Core Concept: "Cattle vs. Pets"
```
┌────────────────────────────────────────────────────────┐
 │ DEPLOYMENT  ➜  "Cattle" (Stateless APIs / Frontends)  │
 │ • Pods are identical and interchangeable.             │
 │ • Random names: vast-api-67df98b4-x2z9k              │
 │ • If one dies, swap it with any new pod instantly.    │
 └────────────────────────────────────────────────────────┘

 ┌────────────────────────────────────────────────────────┐
 │ STATEFULSET ➜  "Pets" (Databases / Distributed Logs)  │
 │ • Each Pod has a unique name and permanent identity.  │
 │ • Predictable names: vast-db-0, vast-db-1, vast-db-2  │
 │ • Each Pod gets its own dedicated, permanent PVC!     │
 └────────────────────────────────────────────────────────┘
```


## yaml file data 
```yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: vast-db
  namespace: vast-dev
spec:
  serviceName: "vast-db-headless"  # 👈 Gives each pod a fixed DNS address
  replicas: 3
  selector:
    matchLabels:
      app: vast-db
  template:
    metadata:
      labels:
        app: vast-db
    spec:
      containers:
      - name: postgres
        image: postgres:16-alpine
        volumeMounts:
        - name: db-storage          # 👈 Mounts the volume generated below
          mountPath: /var/lib/postgresql/data
```
