# Linux Essential Commands & Shell Playbook

---

## 🧠 Core Concepts

* **Shell Prompt Indicators:**
  * `~` (Tilde) => Represents the current user's **Home directory** (e.g., `/home/bhushan` or `/root`).
  * `$` (Dollar sign) => Indicates a **Regular user** shell prompt.
  * `#` (Hash/Pound sign) => Indicates a **Root (Superuser)** shell prompt with full administrative privileges.

* **Environment Variables & `export`:**
  * Setting a variable like `MY_TOOL="/opt/my_tool"` creates a local shell variable that only exists in the current shell session and is NOT visible to child processes or external scripts.
  * The `export` command exports the variable to the shell's environment table, making it available to all child processes and scripts spawned from that shell:
    ```bash
    export MY_TOOL="/opt/my_tool"
    ```
  * To make an environment variable permanent, add the `export` line to `~/.bashrc` (for user) or `/etc/environment` (system-wide).

## 🛠️ Playbook & Commands

### 1. Navigation & Directory Inspection
```bash
# Print current working directory
pwd

# Change directory
cd /path/to/folder

# Go to user's home directory (shortcut)
cd ~
# or simply:
cd

# Go back to previous directory
cd -

# Go up one directory level
cd ..
```

### 2. File & Directory Management
```bash
# List files (detailed with hidden files and human-readable sizes)
ls -lah

# Create a new directory (and parent directories if they don't exist)
mkdir -p /path/to/new_folder/subfolder

# Move or rename a folder from one path to another
mv /path/to/source_folder /path/to/destination_folder/

# Rename a file or folder
mv old_name.txt new_name.txt

# Copy a file
cp source.txt destination.txt

# Copy an entire folder recursively (-r)
cp -r /path/to/source_folder /path/to/destination_folder/

# Remove a file
rm file.txt

# Remove a folder and all its contents recursively (-r) with force (-f)
rm -rf /path/to/folder
```

### 3. Environment Variables & Exports
```bash
# Export an environment variable for child processes in current session
export MY_TOOL="/opt/my_tool"

# Add a directory to PATH
export PATH="/opt/my_tool/bin:$PATH"

# Print an environment variable
echo $MY_TOOL
echo $PATH

# View all active environment variables
env
# or
printenv
```

### 4. Viewing & Searching Files
```bash
# View full contents of a file
cat file.txt

# View file page by page
less file.txt

# Search for a pattern inside files (recursive, line numbers)
grep -rn "pattern" /path/to/search/

# Find files by name
find /path/to/search -name "*.log"
```
