# Linux File System Hierarchy

---

## 🧠 Core Concepts

* **Single Hierarchical Tree vs Windows Disks:**
  * In Linux, there is only **one root folder (`/`)** - all directories and devices are organized in a single hierarchical tree.
  * In Windows/Desktop, there are multiple roots based on disk drives (e.g., `C:\`, `D:\`, `F:\`).
  * In Linux, every user has their own dedicated home space (`/home/<username>`).

* **Core Directory Breakdown:**

  * **`/bin` (User Binaries):**
    * Stands for binary.
    * Contains the most basic, essential commands needed on the operating system (e.g., `ls`, `cp`, `mv`, `rm`, `cat`).

  * **`/sbin` (System Binaries):**
    * Stands for system binary.
    * Contains system-oriented commands and administrative utilities.
    * Running these commands requires administrative / root permissions (e.g., `reboot`, `fdisk`, `iptables`, `ip`).

  * **`/lib` (Shared Libraries):**
    * Holds essential shared libraries needed by the executables in `/bin` and `/sbin`.

  * **`/usr` (User System Resources):**
    * Stands for User System Resources (not user personal files, which are in `/home`).
    * Inside `/usr`, there are also `/usr/bin`, `/usr/sbin`, and `/usr/lib`.
    * Most non-critical user-installed software commands run from `/usr/bin`.
    * **`/usr/local`:** Used for software compiled and installed manually from source. Contains its own `bin`, `sbin`, and `lib`. Software here is available system-wide for all users.

  * **`/opt` (Optional Software):**
    * Used for third-party programs you install (e.g., Google Chrome, cross-compilation toolchains).
    * **Difference between `/opt` and `/usr/local`:**
      * Software that splits its components across standard directories (`bin`, `lib`, `share`) goes inside `/usr/local`.
      * Software that does NOT split and stays bundled inside its own dedicated directory goes inside `/opt/<app_name>`.

  * **`/boot`:**
    * Contains files required for booting the system (kernel images, initramfs, bootloader configuration).

  *(Note: The directories above are generally static and read-only during regular user operations).*

  * **`/etc` (System Configuration):**
    * System-wide configuration files and startup scripts are stored here (e.g., `/etc/passwd`, `/etc/hosts`, `/etc/network`).

  * **`/dev` (Device Files):**
    * Special device files representing hardware devices (webcam, keyboard, hard drives like `/dev/sda`, serial ports like `/dev/ttyUSB0`).
    * Applications and drivers access hardware through these files. Users don't edit these directly.

  * **`/var` (Variable Data):**
    * Contains files to which the system writes data dynamically during normal operation.
    * `/var/log` -> Contains system and application log files.
    * `/var/cache` -> Contains application cache data.

  * **`/tmp` (Temporary Files):**
    * Temporary resources required for running processes. Often cleared on system reboot.

  * **`/media` (Removable Media):**
    * Auto-mount point for removable media (USB flash drives, CDs).

  * **`/mnt` (Manual Mounts):**
    * Mount point for manually mounted external filesystems or temporary storage.

## 🛠️ Playbook & Commands

**1. Inspect the root hierarchy and structure:**
```bash
# List all folders in root with permissions and ownership
ls -la /

# View directory tree of root (1 level deep)
tree -L 1 /
```

**2. Check disk space and folder sizes:**
```bash
# Check mounted filesystems and disk usage in human-readable format
df -h

# Check sizes of folders in /var to find log or cache bloat
sudo du -sh /var/* | sort -hr
```

**3. Inspect hardware block devices and mounts:**
```bash
# List all block storage devices (disks, partitions)
lsblk

# View all currently mounted filesystems
mount | column -t
```
