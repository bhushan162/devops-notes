# Arrays & Vectors

---

## 🧠 Core Concepts

* **Fixed-Size Arrays:**
  * Contiguous block of memory storing elements of the same type.
  * Size is fixed at declaration and cannot grow or shrink dynamically.
  * Array indexing (`arr[i]`) is $O(1)$ direct memory offset access: `base_address + (i * sizeof(element))`.
  * **Size Calculation:** For static stack arrays, size is computed as `sizeof(arr) / sizeof(arr[0])`.
  * **Function Decay:** When passed into a function, an array decays into a raw pointer (`int*`), meaning `sizeof` inside a function will only return the pointer size (4 or 8 bytes), not the number of elements!

* **Dynamic Arrays (`std::vector`):**
  * Dynamic array provided by the C++ Standard Template Library.
  * Automatically handles memory reallocation, growing its internal capacity on the heap as elements are added.
  * Provides built-in functions for size tracking (`.size()`), element insertion (`.push_back()`, `.emplace_back()`), and removal (`.pop_back()`).

## 🛠️ Playbook & Code Snippets

### 1. Static Array Operations
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int arr[] = {3, 1, 2};

    // Find number of elements in a static array
    int n = sizeof(arr) / sizeof(arr[0]);

    // Sort the array in ascending order (sort takes pointer to start and end)
    sort(arr, arr + n); // Result: {1, 2, 3}

    // Print sorted array
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << "\n";

    return 0;
}
```

### 2. Vector Operations
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    // Initialize vector
    vector<int> num = {3, 1, 2};

    // Add elements to the back
    num.push_back(4);

    // Find current size of vector in O(1)
    int n = num.size();

    // Sort the vector in ascending order
    sort(num.begin(), num.end()); // Result: {1, 2, 3, 4}

    // Remove the last element
    num.pop_back(); // Result: {1, 2, 3}

    // Print vector elements
    for (int val : num) {
        cout << val << " ";
    }
    cout << "\n";

    return 0;
}
```
