### memory Handeling
** Pass-by-Value and Pass-by-Reference ** 

1. pass-by-value 
 ```CPP
 #include <iostream>
using namespace std;

void addFive(int num) {
    num = num + 5;                                                              
}

int main() {
    int num = 10;
    addFive(num);
    cout << num;                                        # here vale of num will print as 10 not 15 because in above fuction                                             # we pass-by-value
    return 0;                                           # because pass value num wills dscare as addFive fuction complete
}


``` 

2. pass-by-reference 

```CPP
    void addFive(int &num) { // Notice the & symbol here!
        num = num + 5;
    }

```
- Now, instead of creating a copy in memory, num inside addFive points directly to the original memory address in main(). Modifying it inside the function changes the original value to 15.
- When you pass a standard array into a function, C++ does not copy all the elements. Instead, it passes the memory address of the first element (&arr[0]), so arrays are always passed by reference by default.

2. Iterators 📍 (Pointer-like objects used to traverse containers)
3. Algorithms ⚙️ (Built-in functions like sort(), reverse(), lower_bound())
4. Functors 🛠️ (Function objects)

### Essential STL Algorithms
1. sort(v.begin(), v.end()); sorts a vector in $O(N \log N)$ time.
2. Max/Min Element: *max_element(v.begin(), v.end()); finds the maximum value.   
3. Counting Set Bits: __builtin_popcount(x); returns the number of 1s in the binary representation of integer x.   
4. Next Permutation: next_permutation(v.begin(), v.end()); generates the lexicographically next permutation of an array/vector.
