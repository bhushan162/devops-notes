# C++ Fundamentals & Standard Template Library (STL)

---

## 🧠 Core Concepts

* **Memory Handling: Pass-by-Value vs Pass-by-Reference:**
  * **Pass-by-Value:** A copy of the variable is created inside the function's stack frame. Modifying the copy leaves the original variable in `main()` unchanged.
  * **Pass-by-Reference (`&`):** Instead of creating a copy in memory, the function parameter points directly to the original memory address. Any changes made inside the function modify the original variable.
  * **Arrays and Function Passing:** When you pass a standard array into a function, C++ does not copy all elements. It passes the memory address of the first element (`&arr[0]`), so arrays decay to pointers and are always passed by reference by default.

* **Standard Template Library (STL) Pillars:**
  * **1. Containers 📦:** Data structures used to store data (`vector`, `pair`, `set`, `map`, `unordered_map`, `stack`, `queue`).
  * **2. Iterators 🧭:** Pointer-like objects used to traverse elements of containers (`v.begin()`, `v.end()`).
  * **3. Algorithms ⚙️:** Built-in optimized functions like `sort()`, `reverse()`, `max_element()`, `next_permutation()`.
  * **4. Functors 🎯:** Function objects that can be treated as functions.

* **Core STL Containers Overview:**
  * **`pair<T1, T2>`:** Stores two heterogeneous objects as a single unit (`.first`, `.second`).
  * **`vector<T>`:** Dynamic array that automatically resizes as elements are added.
  * **`set<T>`:** Stores unique elements in strictly sorted order ($O(\log N)$ insertions/lookups via Self-Balancing BST).
  * **`unordered_set<T>`:** Stores unique elements in no specific order ($O(1)$ average lookups via Hash Table).
  * **`map<Key, Value>`:** Stores `(key, value)` pairs sorted by key ($O(\log N)$ lookups).
  * **`unordered_map<Key, Value>`:** Stores `(key, value)` pairs in a hash table ($O(1)$ average lookups).

## 🛠️ Playbook & Code Snippets

### 1. Memory Handling: Pass-by-Value vs Pass-by-Reference

```cpp
#include <iostream>
using namespace std;

// Pass-by-Value: Creates a local copy in memory
void addFiveValue(int num) {
    num = num + 5; 
}

// Pass-by-Reference: & points directly to original memory address
void addFiveRef(int &num) {
    num = num + 5;
}

int main() {
    int num = 10;
    
    addFiveValue(num);
    // Value remains 10 because num was passed by value and the local copy was discarded
    cout << "After pass-by-value: " << num << "\n"; 

    addFiveRef(num);
    // Value changes to 15 because num was passed by reference
    cout << "After pass-by-reference: " << num << "\n"; 

    return 0;
}
```

### 2. STL Containers

**Pair:**
```cpp
#include <iostream>
#include <utility> // Included in <bits/stdc++.h>
using namespace std;

pair<int, string> p = {1, "Striver"};
cout << p.first << " " << p.second; // Prints: 1 Striver
```

**Vector:**
```cpp
#include <vector>

vector<int> v;         // Empty integer vector
v.push_back(10);       // Adds 10 to the back -> [10]
v.emplace_back(20);    // Faster way to add 20 -> [10, 20]
v.pop_back();          // Removes the last element -> [10]
```

**Set (Unique & Sorted):**
```cpp
#include <iostream>
#include <set>
using namespace std;

set<string> cars = {"Volvo", "BMW", "Ford", "Mazda"};

// Add element
cars.insert("Tesla");

// Remove element
cars.erase("Volvo");

// Print set elements (printed in sorted order)
for (string car : cars) {
    cout << car << "\n";
}

// Check size and whether empty
cout << "Size: " << cars.size() << "\n";
bool isEmpty = cars.empty();

// Remove all elements
cars.clear();
```

**Unordered Map (Hash Table Key-Value):**
```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

unordered_map<string, int> ageMap;
ageMap["Alice"] = 25;
ageMap["Bob"] = 30;

cout << "Alice's age: " << ageMap["Alice"] << "\n";
```

### 3. Essential STL Algorithms

```cpp
#include <vector>
#include <algorithm>
using namespace std;

vector<int> v = {4, 1, 8, 3};

// 1. Sort vector in O(N log N) time
sort(v.begin(), v.end());

// 2. Max and Min elements (returns iterator, dereference with *)
int maxVal = *max_element(v.begin(), v.end());
int minVal = *min_element(v.begin(), v.end());

// 3. Counting Set Bits: returns number of 1s in binary representation of integer x
int x = 7; // Binary 0111
int setBits = __builtin_popcount(x); // returns 3

// 4. Next Permutation: generates lexicographically next permutation
next_permutation(v.begin(), v.end());
```
